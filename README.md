# Shree Electricals Khata — Android builds

Signed production builds of the Khata Book Android app.

## Download the app

**[Download the latest APK](https://github.com/KedarUK20/khata-book-releases/releases/latest/download/khata-book.apk)**

1. Open the link on the Android phone.
2. Allow "Install unknown apps" when prompted.
3. Open the downloaded file and install.
4. On first launch, enter the shop computer's Wi-Fi address, for example `http://192.168.1.10:3000`.

## Releases

[All releases](https://github.com/KedarUK20/khata-book-releases/releases) — APK and Play Store AAB for each version.

## Notes

- Package: `com.shreeelectricals.khata`
- Requires Android 7.0 (API 24) or newer.
- The phone must be on the same Wi-Fi network as the shop computer running the Khata backend.
